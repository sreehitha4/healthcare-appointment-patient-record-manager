# Healthcare Appointment and Patient Record Manager

A secure healthcare management system designed for small clinics to manage patient information, appointments, medical history, and prescriptions efficiently.

## Project Overview

The Healthcare Appointment and Patient Record Manager aims to simplify clinic operations by providing a centralized system for patient registration, appointment scheduling, medical record management, and prescription tracking.

The project emphasizes CRUD (Create, Read, Update, Delete) operations, data security, modular design, and software engineering best practices.

## Key Features

- **Patient Management:** Register patients, view details, update information, and search records.
- **Appointment Management:** Schedule, view, reschedule, and cancel appointments.
- **Medical History:** Maintain patient medical histories and clinical records.
- **Prescription Management:** Create and manage prescriptions linked to patient consultations.
- **Authentication and Access Control:** Provide secure login and role-based access.
- **Data Validation and Security:** Validate inputs and protect sensitive patient information.

## Technology Stack

- **Frontend:** HTML, CSS, JavaScript, Bootstrap
- **Backend:** Python Flask
- **Database:** SQLite
- **Version Control:** Git and GitHub
- **Development Environment:** Visual Studio Code
